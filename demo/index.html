Why not play in the browser?

Ironveil is built with Godot 4 and C#. That project cannot currently be exported to the web. A browser version would need a separate, compatible implementation and its own performance and accessibility testing. We won’t present a mock interface as playable.

What a future demo could include

  • A captioned video and step-by-step screenshot walkthrough first.
  • Possibly a small, purpose-built rules demonstration—not the full game—if it teaches the real strategic loop.
  • A separate web-compatible game build only after technical validation.
