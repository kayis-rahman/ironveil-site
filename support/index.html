Support channel

Report a problem

Open an issue on this site’s repository. Include the game version, device and OS, what you expected, what happened, and steps to reproduce it.

Open an issue on GitHub

Issues are public. Do not include passwords, account credentials, payment information, private save files, or other sensitive personal data. Only attach a screenshot if it contains no private information. For private privacy requests, email support@ironvei-game.online. No response time is promised yet.

Frequently asked questions

Can I play offline?

The offline game is designed to run without an account or internet connection. Separate online service code is not part of the approved offline MVP.

Do I need an account?

Not for offline play. The repository contains a separate online account path; online access is not offered as part of the current offline release plan.

Does the game have ads or purchases?

The offline MVP has no ads or in-app purchases. No purchase code or SDK was found in the game repository.

What does Ironveil cost?

No price has been announced. That does not mean the game will be free.

Where can I download Ironveil?

Ironveil is in development; no public store download is available. Check the Release page for status.

How can I report a bug safely?

Use the GitHub Issues link above for non-sensitive reports. Describe the problem without sharing credentials or sensitive personal information. For privacy requests, do not use a public issue; email support@ironvei-game.online.
