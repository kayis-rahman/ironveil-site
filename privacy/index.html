The offline game: single-player on your device

Ironveil is an offline, single-player game against a bot. It can be played without an account or an internet connection, and the offline game makes no network requests: the online client in the code is a plain static class that is not loaded at startup and does not connect until an online screen explicitly asks.

Match saves, match history and settings are stored in the game’s app-specific private storage on the device. They are not cloud-synced; deleting the app or its data removes them.

Data collected: none. The offline game has no sign-up, no login, no advertising, no in-app purchases, and no analytics or crash-reporting SDK. The source audit found no client analytics or event-upload code. The game reads a platform identifier locally when deriving an encryption key for a saved optional online session; the audit found no code sending that identifier to a service.

Analytics on this website

This website can use Google Analytics 4 (GA4) to count page views and clicks on App Store and Google Play links. Analytics is optional and starts off. It does not load or send information unless you choose “Accept analytics” in the banner. You can reject analytics or change your choice later using “Analytics settings” in the footer. Your choice is saved in this browser; if browser storage is unavailable, it applies only until you leave the page.

If enabled, the website sends GA4 the page address with only the utm_source, utm_medium and utm_campaign campaign parameters retained, the page title, a referrer address without query parameters, and store-link clicks without their query strings. Google receives this data to provide the analytics service and acts as a processor for this site. Google’s processing may involve data handling described in Google’s privacy information. Advertising-related consent remains denied and Google Signals and ad personalization are disabled in the site configuration.

The GA4 Measurement ID is configured. Analytics remains off and no analytics script is loaded or data sent unless you accept analytics. This describes the site implementation, not a claim of legal compliance.

Separate online account and match code (not part of the offline game)

The repository also contains a separate, optional online account and match-service path that sits outside the approved offline game. In that code, sign-up and sign-in send an email address and password to a configured service; the server stores the password hashed. After sign-in the password is dropped from the device: the session is stored in an encrypted app-sandbox file and holds the player ID, email, access token and expiry, and online requests authenticate with a bearer token. This describes code in the repository - it is not a claim that online play is part of the current release or that any service is reachable today.

The Pi alpha online mode (planned, not verified live)

A Pi alpha deployment plan proposes persistent accounts and match state in PostgreSQL with a 24-hour production turn window, and leaves alpha retention and data reset as an open decision. None of that has been verified against a running service: the audit evidence marks live server state as unverified, so this page makes no claim about whether the service is live, who operates it, or its logs, backups or retention. If an online alpha is offered, the account data described above plus server-side match state would be involved, and a separately verified privacy notice must be published first.

This website

This is a static informational site with no contact forms. Apart from the optional, consent-gated Google Analytics described above, it loads no third-party scripts, fonts or media. GitHub Pages hosts the site and may process visitors’ IP addresses and technical request information for security and service operation. See GitHub’s privacy statement for its practices.

If you follow a link to GitHub Issues, GitHub’s own privacy practices apply; issue reports are public. Do not post passwords, private account details, payment information or other sensitive personal data there.
