The game

The released game is played offline against a bot. It does not collect or send personal data. It does not require an account, show ads, include purchases or use analytics. Saved matches and settings stay on your device.

If an online alpha is mentioned elsewhere, it is private testing only and is not part of the public offline game described here. Any change to the game’s data practices must be reflected in this policy before release.

This website

This is a static informational website. It does not use advertising trackers, analytics, contact forms or cookies set by the site. The site is hosted by GitHub Pages. GitHub may process visitors’ IP addresses and technical request information for security and service operation; that hosting activity is controlled by GitHub and is not game analytics. See GitHub’s privacy statement for its practices.

The Demo & Media page contains gameplay screenshots from an early build. This site currently includes no video, third-party player or tracker.
