The offline game

The offline game can be played without an account or an internet connection. Match saves, match history and settings are stored in the game's app-specific local data area on the device. They are not cloud-synced by the offline game; deleting the app or its data can remove them.

The current offline MVP has no advertising, in-app purchases, analytics SDK or crash-reporting SDK. The source audit found no client analytics/event-upload code. The game reads a platform identifier locally when deriving an encryption key for a saved optional online session; the audit found no code sending that identifier to a service.

Separate online code and the Pi alpha

The repository also contains a separate, optional online account and match-service path; it is outside the approved offline MVP. In that code, sign-up and sign-in send an email address and password to the configured service. The password is not stored on the device. A signed-in session stores the player ID, email, access token and expiry in an encrypted app-sandbox file; online requests use the bearer token. This describes code, not a claim that online play is part of the current public release.

A Pi alpha deployment plan proposes persistent account and match state in PostgreSQL and a 24-hour production turn window. The supplied audit did not verify a live Pi service, its current configuration, operators, logs, backups or retention. This draft therefore makes no claim about live server operations or retention. Before any online alpha is offered, the owner must verify the actual service and publish a matching notice.

This website

This is a static informational site. Its code uses no advertising trackers, analytics, contact forms or site-set cookies, and loads no third-party scripts, fonts or media. GitHub Pages hosts the site and may process visitors' IP addresses and technical request information for security and service operation. See GitHub's privacy statement for its practices.

The gameplay pages use locally hosted screenshots. If you follow a link to GitHub Issues, GitHub's own privacy practices apply; issue reports are public. Do not post passwords, private account details, payment information or other sensitive personal data there.
